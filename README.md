# Metamorphs (web)

Play in the browser: **https://niqp.github.io/metamorphs-web/**

A browser build of *Metamorphs*, a puzzle game by Alexey Shabalin, published by Alawar Entertainment in 2000. The original Delphi game was decompiled and rebuilt in C++ with SDL3, then compiled to WebAssembly with Emscripten.

Controls: arrow keys move the cursor or the selected piece, Space selects, Backspace or Ctrl+Z undoes a move, F1 opens the game's rules. On touch screens an on-screen pad appears. Progress is saved in the browser.
